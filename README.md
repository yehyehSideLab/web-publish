# Web Publish

统一托管公开网站，每个网站使用独立目录和地址。源码、原始数据在各自项目维护，这里集中保存经确认可公开的发布产物。

- `portal/`：网站入口。
- `sites.json`：网站名称与公开路径登记。
- `sites/<id>/`：各网站可直接托管的静态文件。
- `releases/<id>.json`：对应站点的公开产物版本和文件校验信息。
- `tools/`：单站导入与整站组装工具。
- `.github/workflows/`：统一验证和 Pages 发布入口。

首站为 Since / 判断力，仅公开两个示例和展示所需标签。运行命令、发布记录和实际网址将在工具验收后补齐。
